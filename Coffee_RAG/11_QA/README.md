# QA

## 範圍

整理長答型問題，適合客服、教學、RAG 回答或內容改寫。

- `001_新手該如何選咖啡豆.md`
- `002_咖啡為什麼會酸.md`
- `003_手沖為什麼忽濃忽淡.md`

- `005_義式咖啡和手沖差在哪.md`

## 收錄原則

- 先給短答，再給詳解。
- 回答要能連回知識文章。
- 不確定或情境差異大時，明確寫出條件。
