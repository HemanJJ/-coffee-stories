## 收錄原則

- 庫存、價格、供貨狀態都屬於會變動的資訊，使用前必須回到來源查證。
- 來源頁沒有明確定義的符號，不自行解讀。
- 產品品名可保留中英雙語，方便搜尋與 RAG 檢索。
- 若品項同時涉及產區、處理法、品種，使用內部連結串接，不在產品頁重寫完整百科內容。
