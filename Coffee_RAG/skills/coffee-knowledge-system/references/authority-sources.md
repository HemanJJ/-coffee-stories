# Authority Sources For Coffee_RAG

Use this reference when choosing sources for professional coffee articles, QA, FAQ, or reading plans.

## Tier A: Official, Standards, Research

| Source | URL | Use |
| --- | --- | --- |
| Specialty Coffee Association Brewing Research | https://sca.coffee/brewing-research | Brewing fundamentals, extraction variables, research outputs |
| Specialty Coffee Association Coffee Value Assessment | https://sca.coffee/value-assessment | CVA forms, glossaries, value assessment methodology |
| World Coffee Research Sensory Lexicon | https://worldcoffeeresearch.org/resources/sensory-lexicon | Standard sensory vocabulary for aroma and flavor |
| BrewingScience | https://www.brewingscience.de/ | Peer-reviewed brewing and beverage science research |

## Source Selection Pattern

For each claim:

1. Start with Tier A if the claim is scientific, evaluative, sensory-standard, or methodological.
2. Add Tier B if the claim is about trends, news, culture, events, trade, or business.
3. Add Tier C only for teaching language, examples, product vocabulary, or Taiwan-facing phrasing.
4. Mark any unverified list item as a lead, not as a source-backed claim.
